# Start

Block start là block được thực hiện đầu tiên khi một script được thực hiện. Đồng thời, đây là nơi cho phép chỉ định tham số - biến mà dữ liệu được cung cấp bởi người dùng.

Cụ thể, để script khi được chạy có thể nhập tham số như sau:

![](https://manual-gemlogin-vn.gitbook.io/~gitbook/image?url=https%3A%2F%2F1320481151-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252Fx9Jdg3uhoV9mD7ywwyVw%252Fuploads%252FHp9ELfdtAPV11r45Di5c%252Fimage.png%3Falt%3Dmedia%26token%3D81af9c95-a61a-44f7-8929-2e49dddde5ba\&width=768\&dpr=4\&quality=100\&sign=a50861a8\&sv=2)

Ta có thể chỉ định trong block start như sau (click vào button parameter trong phần thuộc tính của block start):

![](https://manual-gemlogin-vn.gitbook.io/~gitbook/image?url=https%3A%2F%2F1320481151-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252Fx9Jdg3uhoV9mD7ywwyVw%252Fuploads%252FQHuR1oZvE0gx5F18u7dl%252Fimage.png%3Falt%3Dmedia%26token%3D5fa3541f-d440-45d0-846a-876c69381f28\&width=768\&dpr=4\&quality=100\&sign=bc309a3e\&sv=2)

GemLogin hỗ trợ các kiểu giá trị cho tham số như sau:

* Checkbox
* File Path
* JSON
* Number
* String

Với mỗi tham số, ngoài kiểu dữ liệu của tham số, bạn có thể chỉ định các thông tin sau:

* Name: Tên biến sẽ lưu giá trị được truyền vào tham số
* Label: Nội dung hiển thị miêu tả về tham số
* Place holder: Giá trị gợi ý cho tham số
* Default value: Giá trị mặc định của tham số được đặt sẵn
