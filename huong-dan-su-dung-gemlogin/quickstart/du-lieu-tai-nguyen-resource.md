# Dữ liệu tài nguyên - Resource

**Nhập resource**: Thêm tài nguyên vào profile

**Xuất resource**: Xuất tài nguyên ra file

**Xóa resource**: Xóa tài nguyên



* Cấu trúc sử dụng để lấy dữ liệu tài nguyên Facebook định dạng Username|Pass:

-> Để lấy Username trong resource Facebook: \{{variables.resource.Facebook.Username\}}

-> Để lấy Password trong resource Facebook: \{{variables.resource.Facebook.Password\}}

Tương tự với các định dạng khác hoặc tài nguyên khác ....
