# Dữ liệu Proxy - Proxy Data

<figure><img src="../../.gitbook/assets/image (27).png" alt=""><figcaption></figcaption></figure>

**Kiểm tra proxy**

* Cho phép kiểm tra trạng thái hoạt động của proxy đang sử dụng.



**Nhập proxy** ( Áp dụng với proxy tĩnh dạng Http/Socks5)

* Người dùng có thể thêm proxy mới để sử dụng.

\+ No Repeat: Không lặp lại proxy

\+ Repeat: Sử dụng lặp lại proxy

\+ One for all: Dùng 1 proxy thêm cho tất cả profile



**Sao chép proxy**

* Sao chép proxy hàng loạt profile



**Xóa proxy**

* Xóa proxy hiện có khỏi hệ thống.
