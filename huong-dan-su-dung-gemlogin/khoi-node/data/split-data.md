# Split Data

Input variable: Text/String hoặc List.

Delimiter: Ký tự phân tách (ví dụ: ",", "|", ";", " ", etc.).

Extract Mode:

* All Value: Lấy tất cả giá trị sau khi tách.
* Random Value: Chọn ngẫu nhiên một giá trị từ kết quả.
* Nth Value: Lấy giá trị theo thứ tự (nhập thứ tự bên dưới).

Trim Whitespaces: Loại bỏ khoảng trắng thừa ở đầu và cuối các giá trị sau khi tách

Output variable: Gắn kết quả vào biến
