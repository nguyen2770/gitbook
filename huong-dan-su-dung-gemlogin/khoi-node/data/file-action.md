# File Action

Block file action là công cụ hỗ trợ các thao tác liên quan tới file với 2 hành động chính với file là viết và xóa trên file được chỉ định.

![](https://manual-gemlogin-vn.gitbook.io/~gitbook/image?url=https%3A%2F%2F1320481151-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252Fx9Jdg3uhoV9mD7ywwyVw%252Fuploads%252FS9K6cQBidatpPZoNYmgD%252Fimage.png%3Falt%3Dmedia%26token%3D50ee31e5-7071-4a80-8ce5-30e458d53797\&width=768\&dpr=4\&quality=100\&sign=bc45612d\&sv=2)

Bạn có thể chỉ định hành động với file cần thực hiện trong thuộc tính như sau:

Options: cho phép chọn 1 trong 2 hành động được hỗ trợ cần thực hiện với file: viết thêm vào file và xóa file trên máy.

![](https://manual-gemlogin-vn.gitbook.io/~gitbook/image?url=https%3A%2F%2F1320481151-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252Fx9Jdg3uhoV9mD7ywwyVw%252Fuploads%252Ffmht9UNf3vXXI61eGDE6%252Fimage.png%3Falt%3Dmedia%26token%3De5da5884-8339-4ede-978f-609854860357\&width=768\&dpr=4\&quality=100\&sign=f7bf2de3\&sv=2)

1.  Chế độ viết:

    * File path: cho phép bạn chỉ định đường dẫn tới file cần được viết.

    ![](https://manual-gemlogin-vn.gitbook.io/~gitbook/image?url=https%3A%2F%2F1320481151-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252Fx9Jdg3uhoV9mD7ywwyVw%252Fuploads%252Fddta2DvGpHO1MvBoINwc%252Fimage.png%3Falt%3Dmedia%26token%3D37964e47-1440-4824-9c80-0920c9e6e183\&width=768\&dpr=4\&quality=100\&sign=6bbe505a\&sv=2)

    * Input data: cho phép bạn chỉ định dữ liệu cần được viết vào file chỉ đinh.

    ![](https://manual-gemlogin-vn.gitbook.io/~gitbook/image?url=https%3A%2F%2F1320481151-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252Fx9Jdg3uhoV9mD7ywwyVw%252Fuploads%252FhCBDUmTqYFt8ANkTZqBc%252Fimage.png%3Falt%3Dmedia%26token%3Df1effd92-8f59-4aa9-87d6-05a2ea77fe5f\&width=768\&dpr=4\&quality=100\&sign=1843a140\&sv=2)

    * File type: cho phép chỉ định loại file sẽ được viết thêm nội dung mới.

    ![](https://manual-gemlogin-vn.gitbook.io/~gitbook/image?url=https%3A%2F%2F1320481151-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252Fx9Jdg3uhoV9mD7ywwyVw%252Fuploads%252Fqrpw5ClNVtekRMKkes0u%252Fimage.png%3Falt%3Dmedia%26token%3D019d1d2a-afdf-4096-9bad-af5aba5a1cf1\&width=768\&dpr=4\&quality=100\&sign=e51b1367\&sv=2)

    * Write mode: cho phép chỉ định chế độ cần viết: ghi đè hoặc chèn thêm nội dung mới.

    ![](https://manual-gemlogin-vn.gitbook.io/~gitbook/image?url=https%3A%2F%2F1320481151-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252Fx9Jdg3uhoV9mD7ywwyVw%252Fuploads%252FIPM9enuTkKuDwe35Sm6S%252Fimage.png%3Falt%3Dmedia%26token%3D79df8676-ea46-4524-b8c8-be0f10572011\&width=768\&dpr=4\&quality=100\&sign=68e1c34a\&sv=2)

    * File path: cho phép bạn chỉ định đường dẫn tới file cần xóa.
