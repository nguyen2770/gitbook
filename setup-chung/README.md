# Setup chung

<figure><img src="../.gitbook/assets/image (5).png" alt=""><figcaption></figcaption></figure>

**Thanh menu bên trái** trong giao diện cài đặt của **Gemlogin.**

**Các mục trong menu:**

1. **Chung (General)** – Khu vực cài đặt chung, bao gồm **ngôn ngữ, chủ đề, trình duyệt giả lập, và quản lý hồ sơ**.
2. **Tự động hóa (Automation)** – Quản lý các quy trình tự động hóa, cài đặt và chạy script.
3. **Trình duyệt (Browser)** – Cấu hình trình duyệt browser, chọn phiên bản và tùy chỉnh các cafid dặt trên browser .
4. **Biên tập viên (Editor)** – Công cụ chỉnh sửa script no-code, cho phép người dùng tạo và chỉnh sửa quy trình tự động hóa.
5. **Các phím tắt (Shortcuts)** – Tùy chỉnh phím tắt để thao tác nhanh hơn trong phần mềm.
6. **Integrate (Tích hợp)** – Quản lý kết nối với các dịch vụ bên thứ ba như N8N, Make hoặc API tự động hóa khác.
