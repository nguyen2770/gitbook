# Zoom Page

Block zoom page là công cụ giúp bạn tùy chỉnh tỉ lệ hiển thị hiện tại của tab đang kích hoạt (scale). Bạn có thể tùy chỉnh tham só scale theo đơn vị % để trang web hiển thị theo tỉ lệ như mong muón.
