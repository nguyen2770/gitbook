# Upload File

Block upload file được dùng để tải file từ máy tính lên trình duyệt.

<figure><img src="https://manual-gemlogin-vn.gitbook.io/~gitbook/image?url=https%3A%2F%2F1320481151-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252Fx9Jdg3uhoV9mD7ywwyVw%252Fuploads%252F6bWfdJSi6PJaNWvdFc8l%252Fimage.png%3Falt%3Dmedia%26token%3Dbe015919-a35e-4582-8917-a87b829939e3&#x26;width=768&#x26;dpr=4&#x26;quality=100&#x26;sign=15e65cf6&#x26;sv=2" alt=""><figcaption></figcaption></figure>

Block upload file sẽ thực hiện dựa theo cơ chế sau: đầu tiên GemLoginsẽ click vào phần tử được tìm thấy - phần tử cái cần phải là element sẽ mở ra hộp thoại chọn file. GemLogin sau khi phát hiện hộp thoại chọn file này sẽ chọn các file được chỉ định để upload file. Kết quả là các file được chọn sẽ được tải lên y như người dùng thật tải file lên trình duyệt.

<figure><img src="https://manual-gemlogin-vn.gitbook.io/~gitbook/image?url=https%3A%2F%2F1320481151-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252Fx9Jdg3uhoV9mD7ywwyVw%252Fuploads%252FhxoDLSRVFiHDpOVJQyXs%252Fimage.png%3Falt%3Dmedia%26token%3D0f4721c3-7053-4b04-ae8d-bbf875cab008&#x26;width=768&#x26;dpr=4&#x26;quality=100&#x26;sign=10c656ca&#x26;sv=2" alt=""><figcaption></figcaption></figure>

Với cơ chế như trên, block upload file cung cấp các input sau trong thuộc tính:

* Css selector/Xpath input: Cho phép chỉ định phần tử khi click sẽ mở hộp thoại chọn file.

<figure><img src="https://manual-gemlogin-vn.gitbook.io/~gitbook/image?url=https%3A%2F%2F1320481151-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252Fx9Jdg3uhoV9mD7ywwyVw%252Fuploads%252FfvFAIEDv8GYpQn5zyVrs%252Fimage.png%3Falt%3Dmedia%26token%3Df498bc5f-1859-4068-8e67-40dcadfccb08&#x26;width=768&#x26;dpr=4&#x26;quality=100&#x26;sign=8bbb7bd3&#x26;sv=2" alt=""><figcaption></figcaption></figure>

* File path list input: Cho phép chỉ định đường dẫn tới các file cần upload.
