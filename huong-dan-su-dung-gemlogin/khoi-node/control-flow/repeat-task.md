# Repeat Task

Để sử dụng node này bạn cần kết nối với đầu ra thứ 2 `Lặp lại từ điểm` đến nơi mà bạn muốn lặp lại.

Khi bạn muốn thực thi quy trình và sử dụng được với node Số lần lặp, kịch bản sẽ thực thi từ node kết nối với đầu ra thứ 2. Bạn có thể lựa chọn số lần lặp lại bằng cách ghi số lần vào bên trong node.
